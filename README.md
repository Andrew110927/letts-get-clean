# Letts Get Clean

Website for Letts Get Clean, mobile car detailing in Orange County, NY.

- Live site: https://andrew110927.github.io/letts-get-clean/
- `index.html` holds the whole site. Prices, hours, social links and the gallery list are in the `SETTINGS` block near the top of the script.
- `apps-script/Code.gs` is the booking backend that runs in Google Apps Script on the bookings sheet.
