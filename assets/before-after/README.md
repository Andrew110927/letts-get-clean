# Before-and-after drop folder

Put new before-and-after clips and photos here. Then ask Claude to add them to the "Real cars, real driveways" reels
or the before-and-after sliders on the home page.

Before a file goes on the site:

- **Blur every license plate**, and don't show customers' faces or house numbers without their OK.
- Videos: vertical (9:16) phone clips are fine. They get compressed for the web (about 3–7 MB each) when added.
- Photos: one "before" and one "after" from the same angle work best for the slider.
- Only real Letts Get Clean jobs: no stock or borrowed clips. Note any music's source in `MEDIA_LICENSES.md`.
